# Clock In / Out for Agency Staff — wireframe

Clickable prototype of the clock-in/out screen for agency warehouse staff, with the manager screens (Attendance, Payroll, Photos, Rota, Workers, Reports, Settings).

Open it: https://adarshluxsh.github.io/agency-clock-in-out/

Everything runs in the browser. Data is kept in that browser's local storage only, so each person who opens the link sees their own copy.
